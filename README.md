# Сілкіс — світ слов'янської міфології

## Опис проєкту

**Сілкіс** — україномовний багатосторінковий інформаційний вебсайт, присвячений слов'янській міфології, її персонажам, символам, святам і легендам. На головній сторінці розміщено вступ до теми та короткі цікаві факти. Інші сторінки дають змогу ознайомитися з окремими тематичними розділами.

### Розділи сайту

- **Головна (`index.html`)** — знайомство із сайтом та короткі міфологічні історії.
- **Боги (`gods.html`)** — описи богів і богинь слов'янської міфології.
- **Істоти (`creatures.html`)** — відомості про міфічних істот і духів.
- **Символи (`symbols.html`)** — значення традиційних символів і природних образів.
- **Свята (`celebrations.html`)** — традиційні свята й обряди.
- **Легенди (`tales.html`)** — перекази та легенди слов'янського світу.

### Технології та особливості

- **HTML** — структура сторінок та їхній вміст.
- **CSS (`style.css`)** — оформлення та адаптація інтерфейсу до різних розмірів екранів.
- **JavaScript (`menu.js`)** — відкриття й закриття мобільного меню, зокрема клавішею `Escape` та натисканням поза меню.
- **JavaScript (`paragraph-navigation.js`)** — перемикання між абзацами в інформаційних блоках за допомогою кнопок «Назад» і «Далі» та лічильника.

Проєкт не використовує серверну частину, базу даних або систему збирання. Для відображення окремих шрифтів і зображень використовуються зовнішні вебресурси, тому для повного оформлення бажане підключення до інтернету.

## Інструкція із запуску

### Варіант 1 — запуск у браузері

1. Завантажте архів проєкту та розпакуйте його.
2. Відкрийте папку `full-project`.
3. Двічі натисніть файл `index.html` або відкрийте його через браузер.
4. Переходьте між розділами за допомогою навігаційного меню.

Для цього способу не потрібно встановлювати Node.js, додаткові бібліотеки чи налаштовувати базу даних.

### Варіант 2 — запуск через Visual Studio Code

1. Відкрийте папку `full-project` у **Visual Studio Code**.
2. Відкрийте `index.html`.
3. За бажанням установіть розширення **Live Server** і виберіть **Open with Live Server**.
4. Сайт відкриється в браузері за локальною адресою, яку покаже Live Server.

> Примітка: у `.vscode/launch.json` міститься локальний абсолютний шлях із комп'ютера розробника. На іншому комп'ютері його потрібно змінити або скористатися одним із способів запуску вище.
